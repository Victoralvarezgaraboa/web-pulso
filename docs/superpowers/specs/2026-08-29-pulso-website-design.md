# Rediseño web de Pulso Gestión

Pulso diseña sistemas y automatizaciones a medida para pequeñas empresas. La web explica que ordena compras, albaranes, presupuestos, facturas, correos, catálogo y resultados; el control financiero es una consecuencia del orden operativo, no el único producto.

## Mensaje aprobado

**Titular:** Tu negocio tiene una forma única de trabajar. Tus herramientas también deberían tenerla.

**Apoyo:** Diseñamos soluciones a medida para automatizar tareas, ordenar la información y darte control real sobre tu negocio: compras, albaranes, presupuestos, facturas, correos, catálogo y resultados.

## Arquitectura y requisitos

Cabecera mínima; hero “desorden a sistema”; problemas; soluciones a medida; casos; operación a control; método y contacto. Diseño editorial sobrio con las tipografías y verde señal de la marca. Astro entrega HTML semántico y SEO; GSAP explica el flujo, sin scroll-jacking y desactivado con `prefers-reduced-motion`. Responsive desde 320 px, teclado, foco y contraste. Mantener GitHub/Render. Sin integraciones reales ni migración de hosting.
